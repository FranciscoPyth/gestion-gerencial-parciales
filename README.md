# Gestión Gerencial 5K2 — Parciales modelo

Sitio estático con material de práctica para el **2° parcial** de Gestión Gerencial (5K2). Tiene 3 parciales modelo con el mismo formato que el original, una guía de estudio y autocorrección por sección.

## Contenido

- **Guía de estudio** — mapa de los temas de las Unidades 2, 3 y 4 que entran al 2° parcial.
- **Parcial 1 — Riiing** — parcial real del 29/05/2025, resuelto y comentado.
- **Parcial 2 — Bahía Verde** — escenario ficticio sobre cafetería boutique (servucción, e-business, fidelización).
- **Parcial 3 — TechFlow** — escenario ficticio sobre startup SaaS (start up vs scale up, venture capital, B2B).

Cada parcial tiene 4 secciones: crucigrama, OMEPI, orden cronológico de la planificación estratégica, y unir afirmaciones con conceptos.

## Cómo usarlo

Abrí `index.html` en cualquier navegador. No requiere build ni servidor.

Si está en GitHub Pages, se puede abrir directo desde la URL del repo (Settings → Pages → Source: main, root).

## Stack

HTML + CSS + JS plano. Cero dependencias.
